Air Draw System

Gestures

  • 1 finger: draw
  • 0 fingers: eraser (hold ~2s to clear)
  • 2–5 fingers: hold briefly to change color

Keyboard

  • c: clear
  • s: save
  • +/-: thickness scale

Camera access requires HTTPS (or localhost). Deploy this folder to your domain using GitHub Pages, Netlify, or Vercel.
